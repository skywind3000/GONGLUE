金庸群侠传 名字输入

基本输入规则（DOS原版/经典版通用）

声母映射（初始辅音）：
1 = b、2 = d、5 = zh
q = p、w = t、e = g、r = j、t = ch、y = z
a = m、s = n、d = k、f = q、g = sh、h = c
z = f、x = l、c = h、v = x、b = r、n = s

韵母映射（元音部分）：
8 = a、9 = ai、0 = an
u = i、i = o、o = ei、p = en
j = u、k = e、l = ao、; = ang
m = ü、, = ie、. = ou、/ = eng

声调：
6 = 阳平（一声）
7 = 阴平（二声）
3 = 上声（三声）
4 = 去声（四声）
轻声通常不打或直接空格。

操作：输入一串键 → 空格 选字 → 继续下一个字 → 全部输入完按 回车 确认。

名字举例：
徐小侠（VM6 VUL3 VU86）
小虾米（VUL3 VU8 AU3）
